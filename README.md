# Mini CRM - Client Lead Management System

A simple Client Lead Management System built using React, Node.js, Express.js and MySQL.

## Features

- Admin Login
- Add new leads
- View leads
- Edit leads
- Delete leads
- Search leads
- Lead status management
- Follow-up dates
- Notes
- Dashboard statistics

## Technologies Used

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL
